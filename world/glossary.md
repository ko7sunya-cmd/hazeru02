# 用語集

新しい言葉を作ったら、ここに足す。読みと、どの層で使われる言葉かを添える。

| 用語 | 読み | 層 | 意味 |
|---|---|---|---|
| あがり | あがり | 上層 | 新都市の通称。「水から上がった街」と双六の「上がり」をかけた呼び名 |
| みぎわ市 | みぎわいち | 境界 | 水上マーケットの通称。汀（みぎわ）＝水際に立つ市 |
| 底宿 | そこじゅく | 下層 | 旧新宿の通称。親しみを込めた呼び方で、悪い意味はない |
| 封水 | ふうすい | 下層 | 沈んだ建物の窓を厚いガラスに替え、継ぎ目を塞いで内部に空気を保つ改修 |
| 送気塔 | そうきとう | 全層 | 水上から封水建物へ新しい空気を送る塔。上層の屋上に煙突のように並ぶ |
| 降り筒 | おりづつ | 境界→下層 | 水面から下層へ降りるガラスの昇降機。第一口から第七口まである |
| 潜守 | せんしゅ | 下層 | 封水建物と杭を手入れする職人。毎朝の点検が仕事 |
| 濾し貝 | こしがい | 全層 | 杭に付く小さな二枚貝。水を濾して澄ませる。街の水の透明さを支えている |
| 初杭 | はつくい | 上層 | 新都市で最初に打たれた杭。大桟橋の中央に残る |
| 灯幕 | ともしまく | 上層 | 塔の壁面を覆う大きな表示幕。潮位・天気・伝言などを映す |
| 潮見 | しおみ | 上層 | 潮位を見ること。潮見塔の光の帯を見て時刻と潮を知る習慣 |
| 赤鶴 | あかづる | 境界 | 市場の赤い荷揚げクレーンの愛称 |
| 透き廊 | すきろう | 下層 | 沈んだ線路に沿って建物どうしを結ぶガラスの通路 |
| 光井戸 | ひかりいど | 下層 | ビルの谷間で、正午に陽が真上から落ちてくる場所 |
| 灯魚 | ひうお | 下層 | 夜にほのかに光る小魚。量販店だった塔に棲みついている |
| 気送管 | きそうかん | 下層→上層 | 手紙や小包を筒に入れて空気で上へ送る管 |
| 水上町 | すいじょうまち | 外 | 新宿のほかにある、水の上の町々の総称 |
| 沈み物 | しずみもの | 境界 | 下層の手入れで出てきた古い品。市場で売り買いされる |
| 運び虫 | はこびむし | 全層 | 軽い荷物専用の小型配達機。丸いレンズの目をひとつ持つ。気送管が届かない屋上や杭の上を担当する |
| 宛先不明の棚 | あてさきふめいのたな | 下層 | 底郵便局の奥にある、宛名のない手紙の棚。毎年いちばん古い一通を、誰かが一日だけ連れ歩く |
| 同行者 | どうこうしゃ | 全層 | 案内役と一緒にコースを歩く人。つまり読者のこと |
